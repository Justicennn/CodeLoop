# CodeLoop

## 1. 项目简介

CodeLoop 是一款本地终端编程 Agent，支持连续交互下的代码理解与问答、项目故障定位与修复、小型项目自主构建、项目审查与优化建议生成，以及文件、图片等外部信息读取和需求分析，形成覆盖需求理解、实现、反馈、修正与验证的项目级任务闭环。

## 2. Git 仓库

[GitHub：Justicennn/CodeLoop](https://github.com/Justicennn/CodeLoop)

## 3. 运行方式

### 环境配置

推荐使用 Conda，依赖由 `pyproject.toml` 统一管理。

```cmd
conda create -n codeloop python=3.11 -y
conda activate codeloop
cd /d <CodeLoop源码目录>
python -m pip install .
```

### 模型配置

推荐使用 DeepSeek，同时模型访问层支持兼容接口的其他大模型服务。

```cmd
set MODEL_API_KEY=<API_KEY>
set MODEL_BASE_URL=https://api.deepseek.com
set MODEL_NAME=deepseek-v4-flash-vision-exp
```

### 启动

项目目录默认为工作目录。

```cmd
cd /d <目标项目目录>
codeloop
```

## 4. 特色功能说明

### 4.1 项目级能力

支持指定问题修改与优化、项目代码理解与问答、项目审查与优化建议生成、系统自主构建、系统故障定位，以及文件、图片等外部信息辅助下的需求实现。

### 4.2 自主执行与动态规划

Agent 根据真实工具反馈持续进行决策，复杂任务维护结构化计划，并可根据执行结果和用户决策调整实现方向，形成理解、执行、反馈、修正与验证闭环。

### 4.3 安全与用户控制

系统对工作区边界、文件路径、工具参数和命令执行进行约束，阻止越界访问。同时，针对需要授权的操作，通过任务级审批机制交由用户确认，在保证智能体自主执行的同时保留关键操作的用户控制权。

### 4.4 上下文与可靠性

按完整工具周期裁剪上下文，支持同一会话下的连续交互；跨任务仅保留有界的公开对话历史，并依据真实工具调用和命令执行结果形成验证证据，在保证上下文稳定性的同时支持按需验证。

### 4.5 分层架构与可扩展性

系统共分为交互层、Agent 核心层、模型层和执行层，各层职责明确、边界清晰；审批授权、安全约束、上下文管理和验证机制通过明确接口协同工作，使模型、工具和交互方式能够独立替换与扩展。

### 4.6 统一工具与外源扩展

通过统一的工具注册与调用机制管理执行能力，模型调用通过独立接口解耦，并通过适配器模式接入文档、网页和图片等外部信息，支持各项能力独立扩展。
